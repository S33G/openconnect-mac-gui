# Artwork

`connection-hero.png` is original artwork generated with the built-in image-generation tool for this project. It illustrates connection rather than simulating a product screenshot.

`ui-light.png` and `ui-dark.png` are rendered from the actual SwiftUI view using synthetic demo settings. They inherit a macOS accent color; normal app windows inherit system appearance.

The app icon is original vector artwork generated by `scripts/make-icon.swift`.

## Hero prompt

Use case: ads-marketing. Asset type: wide GitHub README hero artwork for an independent native macOS VPN app named OpenConnect Mac GUI. Create a beautiful restrained editorial 3D illustration, 2:1 panoramic composition. Subject: two interlocking open rounded metal-and-frosted-glass links forming a clear continuous connection, with a tiny softly luminous green connection dot. Silvery ceramic, brushed graphite, subtle translucent ice-blue edges. Background transitions elegantly from warm off-white on the left to deep charcoal on the right, evoking macOS light and dark appearance. Soft studio lighting, precise shadows, generous negative space, calm polished premium desktop software aesthetic. Center the sculptural motif; keep it medium size with breathing room. No app window or fake UI, no text or lettering, no company logos, no Apple logo, no watermark, no padlock cliches, no purple. The image should feel thoughtfully crafted and work as a GitHub repository banner.

## Re-render the UI previews

scripts/build-app.sh
